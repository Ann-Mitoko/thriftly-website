Create a purchase confirmation for a completed stock purchase

Records a confirmed stock purchase and reduces the product's available stock by the purchased quantity. The product must belong to the given vendor. Requires the header Authorization: Bearer thriftly-dev-token-2026 (placeholder token until real auth is built).

Authorizations:
bearerAuth
Request Body schema: application/json
required
vendorId
required
integer
productId
required
integer

List past purchases, newest first

Returns purchase history so a consumer can analyse trends. Each record includes the product's current name and brand (not a snapshot from the time of purchase). All filters are optional and combine with AND. Requires the header Authorization: Bearer thriftly-dev-token-2026 (placeholder token).

Authorizations:
bearerAuth
query Parameters
vendorId
integer
Example: vendorId=1

Only purchases from this vendor

productId
integer
Example: productId=1

Only purchases of this product

from
string <date-time>
Example: from=2026-10-01T00:00:00Z

Only purchases at or after this moment

to
string <date-time>
Example: to=2026-10-31T23:59:59Z

Only purchases at or before this moment
